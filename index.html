Every hour Windows will run the recorder in the background. Data is saved to weather_data\ even when browser is closed.
To verify the task: open Task Scheduler → Task Scheduler Library → find WeatherWorld_AutoRecord
To stop: open Task Scheduler → right-click WeatherWorld_AutoRecord → Disable
Or run manually in Command Prompt:
python weather_recorder.py
Loop mode (runs forever, good for always-on PCs):
python weather_recorder.py --loop --interval=60

Recorder runs every hour at :00. Data saved to weather_data/ automatically.
To verify cron:
crontab -l
To remove the job:
crontab -e # delete the WeatherWorld line
Same as macOS — uses cron.
Quick setup:
# Install Python if needed sudo apt install python3 # Ubuntu/Debian sudo yum install python3 # CentOS/RHEL # Run setup bash setup_mac_linux.sh
Or add the cron line manually:
crontab -e # Add this line: 0 * * * * python3 /path/to/weather_recorder.py
Goal: Record weather data in the cloud — no computer needs to stay on.

GitHub Actions (Free)
Upload weather_recorder.py to a GitHub repo.
Add a workflow file that runs it hourly via schedule: cron.
Data gets committed back to the repo as CSV/JSON.

Cost: Free (2000 min/month on free plan)
☁
Google Cloud Scheduler + Cloud Run
Deploy the recorder as a Cloud Run job.
Trigger it hourly with Cloud Scheduler.
Save data to Google Sheets or Cloud Storage.

Cost: Free tier covers light usage
☁
AWS Lambda + EventBridge
Package recorder as a Lambda function.
Schedule with EventBridge (cron).
Save to S3 or DynamoDB.

Cost: Free tier: 1M invocations/month
☁
Raspberry Pi / Always-On PC
Run the recorder on a Raspberry Pi or always-on home PC using --loop mode.

Command:
python3 weather_recorder.py --loop --interval=60

Cost: ~$35 for a Pi Zero 2W
